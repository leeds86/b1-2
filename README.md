# AI로 글·그림·영상 만들어 나만의 광고 만들기

## 미션 소개

이번 미션의 목표는 **기획 의도가 프롬프트를 거쳐 최종 영상으로 구현되기까지의 전체 제작 파이프라인을 스스로 설계**하는 데 있습니다. 가상의 브랜드를 선택해 스토리보드와 10초 이내 광고 영상을 **AI 도구 기반**으로 완성하며, 이미지·영상·오디오 간 일관성 문제를 현실적으로 해결하는 전략과 의사결정을 문서화합니다.

## 최종 결과물

### 1. [스토리보드(기획) 문서](Storyboard.pdf)
- 브랜드 아이덴티티, 캠페인 목표/핵심 메시지, 씬 구성과 사용 도구 목록을 담아 AI 기반 광고 제작 파이프라인을 문서화합니다.
- 모든 씬에는 씬 번호·길이·메시지·화면 구성·내레이션·사용 도구·프롬프트와 결과 요약·파일명을 포함합니다.
- 최소 1개 씬에서 프롬프트 수정 전/후와 수정 이유를 기록해 프롬프트 기획 과정을 설명합니다.

### 2. [광고 영상 파일](https://drive.google.com/file/d/1hnUOblxNm6bj_SBpAUz6-YO30ZB_Tgi2/view)
- 10초 이내 MP4 영상으로, 모든 시각 및 청각 소스는 멀티모달 생성 도구를 사용합니다.
- 영상은 1080p 이상을 권장하며, 24~30fps·H.264·AAC 스펙을 목표로 합니다.
- 광고의 완성도를 고려해 기승전결 구조와 명확한 메시지 전달을 포함합니다.

## 활용 방법

1. 전체 구조를 파악하려면 먼저 이 README를 읽습니다.
2. 영상 제작 파이프라인의 설계가 궁금하면 `Storyboard.pdf`문서를 확인합니다.
3. 최종 결과물은 `Storyboard.pdf`문서 안의 링크를 통해 확인 가능합니다.
